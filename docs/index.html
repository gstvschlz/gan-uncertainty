Training Image Uncertainty

A WGAN-GP catalog of training images for SNESIM, re-run from the code of Scholze, Bassani and Costa (2023).

Summary

Multiple-point statistics (MPS) simulation reproduces curvilinear geology, such as fluvial channels, by copying patterns from a training image (TI). Most studies draw every realization from a single TI. That TI is one interpretation of the geology, so the realizations leave out the uncertainty about the TI itself and understate spatial uncertainty.

This project trains a WGAN-GP on Strebelle's 250x250 channel TI. The trained generator samples a catalog of TIs, and each catalog TI conditions one SNESIM realization. SNESIM still handles the well data. Running SNESIM from the single reference TI gives the baseline.

The paper concludes that the catalog workflow yields higher uncertainty and variability. The re-run below, made with this repository's code, agrees in direction with a small margin.

Sand proportion in this repository's re-run (seed 69096, 50 epochs on an RTX 5090, 100 catalog TIs, 100 realizations per workflow). These are not the paper's figures.

78 of the 100 catalog TIs lie within 0.05 of the reference proportion, and 3 differ by more than 0.10. The catalog realizations spread only slightly more than the baseline (std 0.0300 against 0.0280).

The generator is under-trained relative to the paper. The critic loss was still falling at epoch 50, and about 30-40% of sampled tiles are clean channel networks while 20-30% are grainy. Realization means (about 0.34) sit above the reference proportion. Conditioning on hard data is expected to shift them; this run did not test that.

Reproduce

Install mise; it provides Python 3.11. The setup step installs torch 2.11 from the CUDA 12.8 wheel index, which RTX 50-series GPUs require; the code falls back to the CPU. On the GPU, 50 epochs take about 2 h; on a CPU, 5 epochs take about 10 h. SNESIM runs through snesim.exe, so that step needs Windows. Nothing pretrained ships, so every artifact regenerates.

mise run setup    # .venv and dependencies
mise run train    # WGAN-GP
mise run sample   # the TI catalog
mise run snesim   # realizations plus the single-TI baseline
mise run gifs     # docs/*.gif
mise run check    # shape and facies-proportion assertions

Every stochastic step takes --seed (default 69096). Run mise run <task> -- --help for the flags.

Differences from the 2022 code

  • The generator output is binarised at 0 instead of 0.5. For a 5-epoch generator, 0 gives a catalog sand proportion of 0.264 against 0.267 for the reference; 0.5 gave 0.19.
  • The SSIM ≥ 0.9 filter in sampling is gone. A dtype bug meant it never filtered, and the SSIM between independent TIs is at most about 0.3.
  • The TI file is strebelle.out, renamed from ti_strebelle.out because snesim.exe rejects file names over 30 characters.
